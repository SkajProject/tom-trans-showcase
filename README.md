# TOM-TRANS Gniezno: strona firmy transportowej

> 🔒 Kod strony należy do klienta i nie jest publikowany. To repozytorium pokazuje efekt pracy.

![Strona TOM-TRANS Gniezno](assets/tom-trans.jpg)

**Strona firmy transportowej z Gniezna** (transport ciężarowy, wynajem ciężkiego sprzętu budowlanego z operatorem, wynajem hali magazynowej). Prezentuje ofertę usług, galerię realizacji i formularz kontaktowy.

🌐 [tomtrans-gniezno.pl](https://tomtrans-gniezno.pl)

## Co zawiera

- Strona główna z sekcjami O nas, Oferta i Kontakt
- Osobna podstrona z galerią realizacji
- Dane kontaktowe i formularz kontaktowy

## Stack

HTML5 · CSS3 · JavaScript · PHP
